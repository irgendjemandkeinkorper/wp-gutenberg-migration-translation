## 2024-03-24 - React useMemo for derived state from large collections
**Learning:** In React applications handling large collections (like `batchStatus` representing potentially thousands of crawled pages), deriving state with an O(N) operation (e.g., iterating to count statuses) directly inside the component body can cause significant performance degradation when the component re-renders frequently.
**Action:** Always wrap O(N) derived state calculations for large collections in a `useMemo` hook, with the original collection as the dependency, to prevent unnecessary recalculations on unrelated renders.
