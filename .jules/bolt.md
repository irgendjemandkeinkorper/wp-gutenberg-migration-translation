## 2024-11-21 - [Batch Rendering Re-render Optimization]
**Learning:** During batch conversion with many pages, the `batchStatus` map updates frequently (status changes from pending -> converting -> done/error). Mapping over the entire `batch` array to render list items inside `SourceInputPanel` meant that a single status change caused all list items to re-render, creating O(N) re-renders per status update and significant UI lag.
**Action:** Extracting the individual batch item into a `React.memo` component (`BatchItem`) and passing specific data props (`page` and `itemStatus`) ensures that only the list item whose status actually changed re-renders, dropping the O(N) re-renders down to O(1) for each update.
