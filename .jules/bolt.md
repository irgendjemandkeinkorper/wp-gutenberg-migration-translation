## 2024-05-18 - Memoize batch list items to prevent O(N) re-renders
**Learning:** In React components that render large lists based on a Map state that updates frequently (like `batchStatus` updating continuously during a batch run), rendering the list items directly inside the map function causes the entire list to re-render on every single state update.
**Action:** Extract the list item into a `React.memo` component and pass the specific Map value (e.g., `batchStatus.get(index)`) as a prop. This leverages the stable object references of unchanged Map values to skip unnecessary re-renders for items whose status hasn't changed.
