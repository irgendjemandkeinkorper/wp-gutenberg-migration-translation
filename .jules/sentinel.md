## 2025-02-14 - Fix DOMParser \uFFFD bypass in URL sanitization
**Vulnerability:** XSS bypass in `isSafeUrl` during HTML normalization.
**Learning:** `DOMParser` converts null bytes (`\x00`) in attribute values into the Unicode replacement character (`\uFFFD`). If URL normalization only strips standard control characters, obfuscated payloads like `<a href="java\x00script:alert(1)">` bypass protocol checks (like `startsWith("javascript:")`) because the parsed string becomes `java\uFFFDscript:alert(1)`.
**Prevention:** When validating URLs to prevent XSS (e.g., checking for `javascript:` schemes), always strip all whitespace characters, control characters, and the Unicode replacement character (`\uFFFD`) using `/[\x00-\x20\x7F-\x9F\uFFFD]/g`. This prevents obfuscated payloads from bypassing simple sanitization checks if not explicitly stripped.
